# PR1 — Identité visuelle, écran d'accueil et barre d'actions : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remplacer le panneau latéral et le H1 par une identité « nuit polaire », un écran d'accueil et une barre d'actions basse à cinq entrées, sans changer la scène 3D ni la logique métier.

**Architecture:** `Village.tsx` reste propriétaire de tout l'état (parcours, activités, météo, XR) et de la scène ; l'interface migre dans `src/components/shell/` sous forme de composants présentationnels qui reçoivent état et callbacks par props. Les composants existants (`ActivityControls`, `WeatherControls`, `ChristmasMusic`) sont restylés et deviennent des contenus de panneau ; l'élément `<audio>` reste monté dans `Village.tsx`.

**Tech Stack:** React 19, TanStack Start, Tailwind 4 (tokens oklch), shadcn (Button, Tabs, ToggleGroup, Slider, Textarea, Drawer/vaul), Lucide, Vitest + Testing Library, Playwright (Python) pour les captures.

**Spec:** `docs/superpowers/specs/2026-11-13-refonte-ui-3d-design.md` (sections 5 et 6).

## Global Constraints

- Aucune nouvelle dépendance npm ; polices via `<link>` Google Fonts avec `preconnect` et `display=swap`.
- Toute couleur passe par un token `--*` de `src/styles.css`, en oklch ; aucun hexadécimal dans les composants.
- Icônes Lucide uniquement ; aucun emoji dans un bouton ou un libellé d'état ; tout bouton icône a `aria-label` et `title`.
- Cibles tactiles ≥ 44 × 44 px (`min-h-11 min-w-11`), ≥ 8 px entre cibles (`gap-2`), texte ≥ 12 px, corps 16 px / interligne 1,5.
- Contraste texte/fond ≥ 4,5:1 sur `--card` posée sur l'ambiance « jour ».
- `prefers-reduced-motion: reduce` : pas d'animation d'accueil ni d'orbite automatique ; transitions instantanées (`motion-safe:` sur toute classe d'animation).
- Textes en français ; `Village de Noël` reste le nom.
- Thème sombre unique ; `.dark` reprend les mêmes valeurs que `:root`.
- Ambiance par défaut : `night`.
- Rien n'est committé par l'agent : chaque tâche se termine par « prêt à committer » et les commandes sont données dans le compte rendu final. Aucune mention d'outil IA dans les fichiers.
- Lovable : ne pas toucher `drizzle/`, `supabase/`, `src/generated/`, `src/routeTree.gen.ts`.

## Review Focus

1. `planTour` lève une exception réseau (pas seulement `{ error }`) : le panneau Parcours doit afficher « Le guide n'a pas pu préparer votre parcours. » et rester utilisable — test dans la tâche 3.
2. Souhait vide ou espaces seulement : « Créer mon parcours » reste désactivé sur l'accueil et dans le panneau — tests tâches 2 et 3.
3. Fermer le panneau Musique pendant la lecture : l'`<audio>` n'est pas démonté, la musique continue — test tâche 4 (le hook ne possède pas l'élément).
4. Session XR active : accueil, barre et puce disparaissent (`immersed`) et reviennent à la sortie — vérification manuelle tâche 6 (jsdom ne rend pas `<Canvas>`).
5. Clavier : `Escape` ferme le panneau ouvert et le focus revient sur le bouton de la barre — test tâche 3.
